# Contributing

This repository is maintained by **Leandro Ferrete**. The `main` branch is
owner-only; external changes are accepted only through pull requests after
review.

## Rules

1. **No game files.** Never submit the IPA, `residentevil`, `main.dz`,
   `s3e.icf`, `app.icf`, `MainWindow.nib`, `intro.mp4`, saves, textures,
   audio, models or any other game asset.
2. **No piracy.** Do not link to IPA/game-data downloads or request them in
   issues/PRs. The port requires a legally obtained, decrypted copy.
3. **Code and docs only.** Contributions must be original code, documentation,
   build scripts or artwork you have the rights to, compatible with the MIT
   license used by this port.
4. **Keep third-party credits.** Do not remove copyright/license headers from
   vitaGL, kubridge, vitaShaRK, VitaSDK or other dependencies.
5. **Build before opening a PR.** State the VitaSDK version, the target
   firmware/CFW, and what you tested on hardware.
6. **No secrets.** Remove tokens, IP addresses, serial numbers and personal
   data from logs and screenshots.
